# Benjamin Lepoutre — CV en ligne

> Site CV personnel et professionnel, développé avec Astro. Focus sur la performance, la sobriété numérique et la conformité RGPD.

## 🛠️ Stack Technique

- **Framework :** [Astro](https://astro.build/) (Static Site Generation - SSG)
- **Style :** CSS personnalisé, typographies soignées (_Libre Baskerville_, _Source Sans 3_)
- **Sécurité & Formulaire :** Web3Forms (via une plateforme sécurisée pour contrer le spam)
- **Accessibilité & Print :** Optimisé pour l'affichage écran et doté d'une feuille de style dédiée à l'impression (`@media print`).

## 🚀 Commandes du projet

Toutes les commandes s'exécutent depuis la racine du projet dans un terminal :

| Commande        | Action                                         |
| :-------------- | :--------------------------------------------- |
| `npm install`   | Installe les dépendances du projet             |
| `astro dev`     | Lance le serveur de développement local        |
| `astro build`   | Compile le site de production dans `./dist/`   |
| `astro preview` | Prévisualise la version de production en local |
| `astro check`   | Vérifie les erreurs de type et de syntaxe      |
